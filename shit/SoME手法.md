# 从 SoME 获奖作品里提炼的讲解手法

每条是一种可以搬到别的题目上的做法：遇到哪一类难点，画面怎么安排，参数怎么随 t 变。出处只给一句话和代码位置，最后一行写用到 t 检验视频（为什么除以 n − 1，t 分布从哪里来）上是什么样子。

---

## 1. 让朴素方案在同一个画面里坏掉，坏的样子指向要补的那一项

**用在**：要引入一个"多出来的项"或"更复杂的方法"，观众会问"为什么不用简单的"。

**做法**：
- 先用朴素方案原样跑一遍，画面、控件都和后面的正确方案相同。
- 失败要表现为一个具体的、看得见的异常状态，不能只是"不太好"。异常的形状要直接暗示缺了什么。
- 下一步只改一个量，同一个画面恢复正常。
- 失败版本要真的按朴素方案计算，不能手写一个坏画面。

**出处**：
- 复杂性科学：萤火虫模型去掉自转频率 ω，箭头全部对齐却一只不闪，补上 ω 才闪（`2_FirefliesSynchronisation.tsx:106-132`；原作把角度硬写成 0，是摆拍，照做时要真跑）。
- 计算机怎么表示数：小数点位置编码越界时读数是"?"，下一个演示同一编码改成灰色虚拟零（`moving-point-demo.ts:20-41`，只靠 `type` 从 `simple` 换成 `hypervalues`）。
- 藏在平板里的图像：直接沿损失梯度走是一团方向乱跳的箭头，换成泊松方程解出的平滑速度场（`create_mesh.jl:478-494`）。
- 弦艺术：伪逆解出"画 −6.3 根线"。

**用到 t 检验**：
- 用除以 n 的样本方差反复抽样，直方图的中心稳定落在 (n−1)σ²/n，在 σ² 左边；只把分母换成 n−1，直方图中心回到 σ²。
- 用 s 代替 σ 算 z，按正态表拒绝的比例明显超过 5%，超出的部分全在尾巴上；换成 t 分布的临界值，比例回到 5%。

## 2. 把"这一步是被迫的"画成：列出全部候选，逐个排除，只剩一个

**用在**：论证里某一步"只能这样"，口述时观众要在脑子里枚举所有可能再排除。

**做法**：
- 把当前这一步的全部候选同时摊开，排成一排小图。
- 违反约束的候选变红，同时在主画面上闪出它违反的那一处。
- 剩下的唯一一个变亮，主画面执行它。
- 每一步固定同样的几拍，越往后越快。

**出处**：解锁图案，每种斜率在 3×3 里的全部放法画成小网格，碰到已用点的排除，剩一个就是下一步（`chapter_1to3.py:71-95` 枚举放法，`676-769` 的 `step()` 固定五拍）。

**用到 t 检验**：自由度。给定 n 个数的均值，前 n−1 个偏差可以随便拖；第 n 个偏差的候选值摊成一条数轴，只有让偏差和为 0 的那一个点亮，其余全灭。"少一个自由度"就是看到最后一个没得选。

## 3. 全局约束做成一排常驻的格子，每一步消耗一格，冲突时两处同时标红

**用在**：约束是对整体说的（两两不同、总和固定、每样只用一次），观众没法一眼判断是否满足。

**做法**：
- 每种"资源"一个图标，图标的样子就是它在主画面里的样子。
- 图标常驻在主画面旁边；主画面每走一步，对应图标点亮。
- 违反约束时，新的那处和它撞上的旧的那处同时变红。
- 定义第一次出现时，用"把整个对象压缩成图标"来演：剩几个图标就是定义里的那个数。

**出处**：解锁图案的斜率图标，线段飞进同斜率的图标，蛇形图案剩 2 个、乱画的剩 7 个；画线时图标点亮，撞斜率时新旧两段同时变红（`chapter_1to3.py:52-68`、`233-290`、`576-625`）。

**用到 t 检验**：n 个偏差旁边放一排 n 个格子，每拖定一个偏差点亮一格；"偏差和为 0"这个约束让最后一格自动点亮、不可拖。

## 4. 不变量是唯一不经过变换的东西

**用在**：要说明某个量在某类变换下不变。

**做法**：
- 场景里的一切都写成 `T(参数)(对象)` 来画。
- 不变量单独画，不经过 `T`。
- 拖参数时，整幅画面都在变，只有不变量静止。
- 再放一个点特意落在不变量上，拖动时它沿着不变量滑。

**出处**：用 Desmos 讲相对论，网格、光线、世界线都写成 `L((…))`，双曲线族 `y^{2}-x^{2}=C^{2}` 不经过 L；橙线终点的间隔 0.954 正好落在加粗的 C₀=0.95 那条上（洛伦兹变换文件 xa6ytgjqtp，表达式 11、12、33、36、38、39）。

**用到 t 检验**：把数据和假设均值 μ₀ 一起平移、一起按正的比例缩放（换单位），数据点、均值、标准差、μ₀ 都跟着动，t 统计量的读数不动。

## 5. 两种理论用同一个场景，只换一组参数

**用在**：比较两种理论或两种方法，差别容易被讲成"差不多，只是略有不同"。

**做法**：
- 场景、对象、视角全部共用，只把参数换成另一组。
- 比较落到一个几何事实上：某个东西保住了还是被破坏了。

**出处**：用 Desmos 讲相对论。
- 光行差的相对论版和伽利略版只差矩阵四个元素。相对论版光线仍贴着光锥，伽利略版光锥被剪切歪了（ouj1bwauoo 和 1xpcvjooj7，表达式 12、14、18、20）。
- 旋转和洛伦兹变换也只差四个元素和一个正负号。

**用到 t 检验**：同一组抽样动画，一次用真 σ 标准化，一次用样本 s 标准化，两张直方图叠在标准正态曲线上：前者贴住，后者尾巴溢出曲线。

## 6. 一个离散参数推广到连续：整数情形当刻度，连续值是刻度间的指针，先在熟悉的类比上演一遍

**用在**：要推广的东西原来只在整数上有定义，观众想象不出中间值。

**做法**：
- 画一根刻度尺，每个整数刻度标上已知的对象，对象和主图里对应曲线同色。
- 指针在刻度之间滑，主图里的曲线连续地从一个已知对象变到下一个，颜色也在两个刻度色之间渐变。
- 先在观众已经接受的推广上演一遍（分数次幂），再原地换刻度标签，换成要讲的新推广，版式不变。

**出处**：
- 分数阶导数视频 0:26–1:08。先量指数，x³、x²、x、1 是刻度；再原地换成 f、f′、f″、f‴。
- 凯莱图：同一张 A₅ 图，把一种边的长度连续收到 0，在十二面体和二十面体之间来回变（页面源码 599–619 行，`linkforcectxx.distance(d => [0, 280][d.group])`）。

**用到 t 检验**：自由度刻度尺，刻度标 ν = 1、2、5、30、∞，∞ 处标"标准正态"。指针滑动时 t 分布的尾巴连续变薄，ν 很大时贴住正态曲线。

## 7. 随机性固定住，只动参数；参数固定住，只重抽

**用在**：展示随机系统随某个参数怎么变。每个参数值独立抽样，画面会整片闪烁，看不出变化趋势。

**做法**：
- 给每个随机元素一个固定的随机数，参数只决定"随机数小于参数就出现"之类的判定。参数变化时画面单调、连续地生长。
- 另外单独演示：参数不动、重抽随机数，说明每一张都是合法样本。
- 两种操作分开演示，一个说明趋势，一个说明分布。

**出处**：渗流视频 5:23–7:56。每条潜在边上印一个 0 到 1 的随机数，"数字小于 p 就接通"；同一批数字下拖 p，团簇连续合并；16:29 起又把这套做法直接用来证明连通概率随 p 单调。

**用到 t 检验**：抽样分布动画里，每次抽样的随机数按编号固定（`render(ctx, t)` 本来就要求确定性）。增大 n 时，已有的样本点不变，只是多出新的点，直方图连续收窄而不是整片重洗。

## 8. 两个可能的分支各配一个小窗，同一个游标同时驱动

**用在**：一个量在某个区间里有两个可能的取值，或同一操作在两个条件下结果不同，要说明它们在某处合并或分开。

**做法**：
- 主图上一根竖线游标。
- 每个分支一个小窗，小窗的位置和分支的位置对应：上支配上窗，下支配下窗。
- 游标扫过合并点时，两个小窗变成一样。

**出处**：
- 复杂性科学：磁化强度曲线的上下两支各配一个晶格窗（`1_IsingMagnetizationGraph.tsx:211-217` 画两支，`270-276` 一个鼠标位置给出两个值，`302-314` 分给上下两窗；原作曲线是手写的，照做时要用真实模拟数据）。
- 分数阶导数视频 17:43：下限 a 不同的左右分屏。做一次半阶导数，两屏结果不同；再做一次，两屏都和普通导数重合。

**用到 t 检验**：双侧检验的左右两个尾巴各配一个小窗，显示落在尾巴里的样本；游标拖动显著性水平，两个窗里的样本数同步增减。

## 9. 从图片层面写等式，再对每一项同时做同一个变形，得到抽象形式

**用在**：要把具体对象改写成向量、矩阵，观众不知道为什么要"拉直"，也不知道矩阵里装的是什么。

**做法**：
- 先用具体的小图写出加法式，系数用开关值（0 或 1）。
- 然后让每一项小图同时做同一个变形（比如逐行拉直成一列），等号两边一起变，等式仍然成立。
- 变形后的列收进方括号，成为矩阵；系数收进另一对方括号，成为向量。颜色从此固定。
- 开关值的设定要留到后面用：解出非法值时，观众不用解释就知道错了。

**出处**：弦艺术视频 2:50–4:59。每根线是一张小像素图，"×1 + ×1 + ×0 = 笑脸"，所有小图同时拉直成列，收成 A；8:30 伪逆解出 −6.3，观众立刻知道"画不了负 6.3 根线"。

**用到 t 检验**：n 个数据点写成 n 维向量，均值部分和偏差部分写成两个向量相加。偏差向量被约束在"各分量和为 0"的那个 n−1 维面上，这就是自由度的几何意义。

## 10. 一个导出量的辅助小窗，第一次出现时固定位置，后面不同的问题都回到它

**用在**：后面有好几个问题都可以归结到同一个导出量上，每次单独解释会各需一套。

**做法**：
- 第一次引入导出量时，开一个带标题的小窗，固定在画面某处，单独画它的轨迹。
- 后面遇到新问题，把新问题改写成"看这个小窗里的某个特征"：在哪里过轴、贴不贴某个圆。

**出处**：贝塞尔曲线视频。速度箭头尖端的轨迹画在固定的"Derivative"小窗里（6:58）。13:10 讲包围盒，变成看小窗曲线在哪里过坐标轴；16:18 讲匀速，变成看它贴不贴一个圆。

**用到 t 检验**：一个固定的"抽样分布"小窗。讲样本方差偏小时看它的中心，讲 t 分布时看它的尾巴，讲 p 值时看阴影面积，始终是同一个窗。

## 11. "去向"问题改写成"大小"问题

**用在**：问题本来是"每一份东西被送到哪里"（映射、输运），追踪每一份的去向太复杂。

**做法**：
- 用同一个编号把来源格子和目标格子绑在一起，问题变成"每个来源格子该多大"。
- 把变形后的来源网格单独画出来，不画任何去向，网格的疏密本身就是目标图。

**出处**：藏在平板里的图像。透镜面上第 (i, j) 格的面积正比于第 (i, j) 个像素的亮度，损失就是"面积减亮度"（`create_mesh.jl:465-470` 的 `D = Float64.(LJ - img)`）；迭代后的网格做线框渲染，就是那只猫。

**用到 t 检验**：把正态分布和 t 分布都画成"等概率格子"：每格包含同样多的概率。t 分布的格子在尾部明显更宽，"尾巴更厚"直接读成格子宽度。

## 12. 开头让人提出反对，结尾的正式工具正好回答这个反对

**用在**：正式定义（极限、ε-δ、无偏性）看起来凭空冒出、繁琐，观众不知道它在防什么。

**做法**：
- 开头用一个直观但有漏洞的论证，让一个角色当场提出具体的反对。
- 正式工具出场时，把它化简到和那个反对针锋相对的最小形式，再把那个角色请回来。

**出处**：微积分的来历视频。3:13 希腊人以"无穷不存在"拒绝圆面积论证；Archimedes 的反驳全靠一排图形比大小，顺序一翻就是矛盾。23:04 讲 ε-δ 时，画面只剩"a < b"，Archimedes 回来。

**用到 t 检验**：开头有人反对："为什么偏偏除以 n−1，n−2 不行吗？"到讲无偏性时，把期望写成 E[除以 k 的样本方差] = (n−1)σ²/k，只有 k = n−1 时等于 σ²，回答的正是开头那句。
