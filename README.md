# Learning Videos

用代码绘制动画的讲解视频。

| 目录 | 内容 |
|---|---|
| `player/` | 网页播放器：逐帧绘制的视频、章节、字幕、每节小题。可以单独使用，见 `player/README.md` |
| `references/` | 参考资料：`writing.md` 是文案写作参考（3Blue1Brown 数学科普比赛的评审标准、写作建议、获奖作品拆解），`animation/` 是两份值得借鉴的动画源码 |

视频项目 `t-test/`（t 检验与自由度）目前在分支 `claude/fervent-cray-lnh6av` 上，那里也用这份播放器。

大文件（配音 wav、背景音乐、渲染出的视频）不放进仓库，放在 GitHub Release 里。

画面和界面上的文字遵守 [`STYLE.md`](STYLE.md)，比如不用间隔号。
