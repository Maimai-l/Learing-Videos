# t 检验与自由度

为什么除以 n − 1，t 分布从哪里来。九节动画讲解，22 分 18 秒。

## 看视频

| 文件 | 说明 |
|---|---|
| `t检验与自由度.html` | 网页版播放器：动画、字幕、章节跳转，每节末尾一道小题 |
| `t检验与自由度.m4a` | 网页版的音轨（配音和背景音乐） |
| `t检验与自由度.srt` | 字幕文件 |

把 `.html` 和 `.m4a` 下载到**同一个文件夹**，用浏览器（Chrome、Edge、Safari、Firefox）打开 `.html` 即可，不需要联网。

MP4 版（1080p、60 帧，字幕在画面里）在 Release `t-test-video` 里。

## 其它位置

- 制作这个视频的源代码：分支 `claude/fervent-cray-lnh6av` 的 `t-test/` 目录，制作流程见 `t-test/docs/制作说明.md`。
- 播放器：分支 `main` 的 `player/`。
- 配音和背景音乐的原始文件：Release `resources`。
