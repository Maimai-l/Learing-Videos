# t 检验视频：制作说明

这份文件记录已经定下来的做法，后面的制作以它为准。

## 已确定

- 主要观众是作者本人，不考虑发布平台的规定和惯例。
- 画面：深色背景；全部用代码绘制，不用图片素材，不用角色。
- 成品两份：
  - HTML：动画、音频、字幕走同一条时间轴，可按章节跳转；每节末尾有一道可点开答案的小题。
  - MP4：由同一个 HTML 逐帧渲染，1920×1080、60 帧，字幕烧进画面，另附 .srt。
- 片名用正常标题。背景音乐用作者提供的轻音乐。
- 旁白先用 `materials/旁白.srt` 这一版。以后可能重新生成配音，届时会有新的 srt，
  所以动画按字幕里的词句定位时间，换了 srt 以后重新对齐，而不是写死秒数。
- 字幕显示时，把给 TTS 的读法换回符号：缪 → μ，艾普西隆 → ε，西格玛平方 → σ²，纽 → ν，n 一减 1 → n₁ − 1 等。

## 制作流程

所有命令在 `t-test/` 目录下运行。

| 步骤 | 命令 | 产物 |
|---|---|---|
| 1. 下载配音和 BGM | 从 Release `resources` 下载到 `build/audio/` | `voice_over_ttest.wav`、`BGM.wav` |
| 2. 语音识别（带逐字时间） | `ffmpeg -i build/audio/voice_over_ttest.wav -ac 1 -ar 16000 build/audio/voice16k.wav`<br>`python3 tools/asr.py build/audio/voice16k.wav build/asr.json` | `build/asr.json` |
| 3. 旁白逐字对齐 | `python3 tools/align.py materials/旁白.txt build/asr.json build/align.json` | `build/align.json` |
| 4. 时间轴 | `node tools/build-timeline.mjs` | `build/timeline.json` |
| 5. 公式 | `node tools/build-tex.mjs` | `build/tex.json` |
| 6. 音轨 | `python3 tools/mix.py build/timeline.json build/audio/voice_over_ttest.wav build/audio/BGM.wav build/audio/mix` | `build/audio/mix.m4a` |
| 7. 截图检查 | `node tools/snap.mjs out/snaps 12.5 30` 或 `--sheet 6 76 24` | PNG |
| 8. 渲染视频 | `node tools/render.mjs --out out/t检验与自由度.mp4` | MP4 |

换新配音时：替换 `materials/旁白.txt`、`materials/旁白.srt` 和 wav，从第 2 步重跑。
字幕 srt 只用来分句，时间全部来自对齐结果（原 srt 的时间是估算的，最多差 2 秒）。
场景里按旁白原文（`旁白.txt` 的写法）定位时间；找不到的词句会在第 5 步打印出来。

## 画面约定

- 颜色只表达一种含义：数据点暖白，真实均值 μ 红，样本均值 x̄ 蓝，误差 ε 橙，
  偏差 x − x̄ 浅蓝，σ 和方差紫，估计值 s 青绿，正的乘积绿、负的乘积粉红，强调色淡金。
- 公式用 MathJax（New Computer Modern 字体）转成字形路径；数轴刻度和数字也用同一字体。
- 中文用思源黑体（Noto Sans SC），标题用思源宋体（Noto Serif SC）。
- 每节之间加 1.8 秒停顿，显示章节卡片；BGM 在说话时压低，停顿时稍微抬起。
