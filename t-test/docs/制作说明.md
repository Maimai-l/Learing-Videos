# t 检验视频：制作说明

这份文件记录已经定下来的做法，后面的制作以它为准。

## 已确定

- 主要观众是作者本人，不考虑发布平台的规定和惯例。
- 画面：深色背景；全部用代码绘制，不用图片素材，不用角色。
- 成品两份：
  - HTML：动画、音频、字幕走同一条时间轴，可按章节跳转；每节末尾有一道可点开答案的小题。
  - MP4：由同一个 HTML 逐帧渲染，1920×1080、60 帧，字幕烧进画面，另附 .srt。
- 片名用正常标题。背景音乐用作者提供的轻音乐。
- 旁白先用 `materials/旁白.srt` 这一版。以后可能重新生成配音，届时会有新的 srt，
  所以动画按字幕里的词句定位时间，换了 srt 以后重新对齐，而不是写死秒数。
- 字幕显示时，把给 TTS 的读法换回符号：缪 → μ，艾普西隆 → ε，西格玛平方 → σ²，纽 → ν，n 一减 1 → n₁ − 1 等。

## 制作流程

所有命令在 `t-test/` 目录下运行。

| 步骤 | 命令 | 产物 |
|---|---|---|
| 1. 下载配音和 BGM | 从 Release `resources` 下载到 `build/audio/` | `voice_over_ttest.wav`、`BGM.wav` |
| 2. 语音识别（带逐字时间） | `ffmpeg -i build/audio/voice_over_ttest.wav -ac 1 -ar 16000 build/audio/voice16k.wav`<br>`python3 tools/asr.py build/audio/voice16k.wav build/asr.json` | `build/asr.json` |
| 3. 旁白逐字对齐 | `python3 tools/align.py materials/旁白.txt build/asr.json build/align.json` | `build/align.json` |
| 4. 时间轴 | `node tools/build-timeline.mjs` | `build/timeline.json` |
| 5. 公式 | `node tools/build-tex.mjs` | `build/tex.json` |
| 6. 音轨 | `python3 tools/mix.py build/timeline.json build/audio/voice_over_ttest.wav build/audio/BGM.wav build/audio/mix` | `build/audio/mix.m4a` |
| 7. 截图检查 | `node tools/snap.mjs out/snaps 12.5 30` 或 `--sheet 6 76 24` | PNG |
| 8. 渲染视频 | `node tools/render.mjs --out out/t检验与自由度.mp4 --audio build/audio/mix.wav --crf 17` | MP4（约 90 分钟） |
| 9. 字幕文件 | `node tools/export-srt.mjs` | `out/t检验与自由度.srt` |
| 10. HTML 播放器 | `node tools/bundle.mjs`（`--artifact` 生成可发布的小音轨版） | `out/t检验与自由度.html` + `.m4a` |

开发时看效果：`node tools/server.mjs`，打开 `/src/index.html?t=60`（动画）或 `/src/player.html`（播放器）。
播放器本身在仓库根目录的 `player/`，和其它视频共用；本视频接入它的代码是 `src/player/start.js`，
小题在 `src/player/quizzes.js`。
`python3 tools/check-scenes.py src/scenes` 检查有没有在 `draw()` 里调用 `tex()`：公式必须在构建场景时创建，
否则第 5 步收集不到。

换新配音时：替换 `materials/旁白.txt`、`materials/旁白.srt` 和 wav，从第 2 步重跑，
再把新的 `build/asr.json`、`build/align.json` 复制到 `data/` 提交（第 4 步在没有 `build/align.json` 时读
`data/align.json`；有了 `data/asr.json`，只改旁白文字时不必重新做语音识别，从第 3 步开始即可）。

在 GitHub 上出成品：仓库的 Actions 里运行 “t-test video” 工作流（`.github/workflows/t-test-video.yml`）。
它从 Release `resources` 下载配音和背景音乐，按 `data/align.json` 做第 4–10 步，
把 MP4、HTML 播放器和音轨、字幕发布到 Release（默认标签 `t-test-video`；已存在就替换里面的文件）。
发布用英文文件名（`t-test.mp4` 等），因为 GitHub 会改掉文件名里的中文；Release 页面上显示中文说明。
整个过程约 1.5–2 小时。
字幕 srt 只用来分句，时间全部来自对齐结果（原 srt 的时间是估算的，最多差 2 秒）。
场景里按旁白原文（`旁白.txt` 的写法）定位时间；找不到的词句会在第 5 步打印出来。

## 画面约定

- 颜色只表达一种含义：数据点暖白，真实均值 μ 红，样本均值 x̄ 蓝，误差 ε 橙，
  偏差 x − x̄ 浅蓝，σ 和方差紫，估计值 s 青绿，正的乘积绿、负的乘积粉红，强调色淡金。
- 公式用 MathJax（New Computer Modern 字体）转成字形路径；数轴刻度和数字也用同一字体。
- 中文用思源黑体（Noto Sans SC），标题用思源宋体（Noto Serif SC）。
- 每节之间加 1.8 秒停顿，显示章节卡片；BGM 在说话时压低，停顿时稍微抬起。
- 停顿：`src/config.js` 的 `pauses` 按“第几段之后”（从 1 数）加秒数。现在是第 11 段后 1.4 秒（两条模拟线之后），
  第 40 段后 1.0 秒（“自由度的两个作用”那张图之后）。改了以后要重跑第 4、5、6 步。
- 字幕和标签里的变量（s、n、t、ν、σ²、s₁² 等）用公式字体的斜体，和公式一致；正文字体里的 ν 看起来像 v。
  标签写成 `mixed('自由度为 $\\nu$ 的分布')`，`$…$` 之间按公式排；字幕自动识别单个字母的变量。
- 公式里的中文（`\text{方差}`）按公式字号排，不加字距。

## 小题

`src/player/quizzes.js`，每节一道，考的是理解而不是复述：
换一组数据比较、误差完全相关时平均值的方差、p 值的含义、用恒等式直接算平方和、三组数据的自由度、
为什么误判率超过 5%、分母恒为 1 时的分布、两组相同时的韦尔奇自由度、20 批数据时的结论。
其中的数都用 scipy 复算过：t = 34.8 与 2.25、p = 0.0244、9.78、E[s]/σ = 0.921（n = 4）、14.5%、
2.04、ν = 18、t = 4.50（ν = 19，界限 2.093，p = 0.00025）。

12.2%、10.7%、7.8%、5.9%、5.0%；n = 4 时一百万次模拟 14.49%，P(s < σ) = 0.609；韦尔奇例子 ν = 4.86。
