一家工厂试用了一种新工艺，一共生产了五批产品。每一批都测了合格率，看它比旧工艺高出多少个百分点，结果是：1.8，负 0.2，2.5，0.3，1.1。

平均下来，新工艺高出 1.1 个百分点。不过这五个数并不整齐，有正有负，最大的是 2.5，最小的是负 0.2。我们要判断的是：这 1.1 反映的是新工艺的效果，还是随机波动碰巧平均出来的。

如果一直这样生产下去，无数批产品的平均提升，叫作真实均值，记作缪。假如新工艺毫无作用，缪就是 0。这时，五个数的平均值通常会偏离 0 多远？如果平均值偏离 0 达到 1.1 是常有的事，这组数据就说明不了什么；只有当这样的偏离很少见时，它才算得上证据。

每个数据与真实均值之差，叫作误差，记作艾普西隆。这五个数是从所有可能的产品中抽出来的，叫作样本，它们的平均值叫作样本均值。

假设新工艺无效，每次随机抽五个数，算一次样本均值，再把它记在下面这条线上。重复很多次以后可以看到，样本均值的分布比单个数据的分布窄得多。这是因为几个数据的误差有正有负，平均的时候会互相抵消一部分。

重复抽样很多次，误差有时为正、有时为负，平均下来是 0。画面上用 E 表示这种重复抽样中的平均。误差的平方则不同，它不会是负数，所以不会正负抵消；它在重复抽样中的平均，反映了误差通常有多大，这就是方差，记作西格玛平方。另外，我们假设各批数据互不影响，也就是相互独立。

样本均值的误差，等于各个误差的平均。需要算的是：样本均值的误差平方，在重复抽样中平均是多少，这就是样本均值的方差。分母的 n 平方以后是 n 平方，可以提到外面。剩下的就是：n 个误差加起来再平方，平均是多少。

先看只有两个误差的情形。把两个误差之和的平方展开，得到的四项正好可以排成一个方格：对角线上是两个误差各自的平方，另外两格是两个误差的乘积。

现在逐格求平均。对角线上是误差的平方，平均都是西格玛平方。另外两格不一样：两批数据互不影响，不管第一批的误差是多少，第二批的误差平均起来仍然是 0，乘上第一批的误差以后，平均还是 0。于是，两个误差之和的平方，平均是两份西格玛平方。

误差多了也是一样。n 个误差之和的平方，展开后是一个 n 行 n 列的方格。对角线上有 n 格，每格平均西格玛平方；其余的格子平均都是 0。所以总和平均是 n 份西格玛平方。

再除以 n 平方，样本均值的方差就是西格玛平方除以 n。方差开平方叫作标准差，它和数据的单位相同。所以样本均值的标准差是西格玛除以根号 n；五批数据，就是西格玛除以根号 5。数据越多，样本均值越稳定；不过波动是按根号 n 缩小的，数据要增加到原来的四倍，波动才会减半。

有了这个结果，问题就可以说得更准确：如果新工艺无效，样本均值偏离 0 达到 1.1 或更远，概率有多大？要算这个概率，还得知道样本均值服从什么分布。我们假设每批数据都服从正态分布，这是一种左右对称、中间高、两边低的钟形分布。这样，样本均值也服从正态分布，均值是缪，方差就是刚才推出的西格玛平方除以 n。

均值为 0、标准差为 1 的正态分布，叫作标准正态分布，它的尾部面积有现成的表可查。任何一个正态分布，比如均值为 m、标准差为 d，要求它大于 a 的概率，可以先平移横轴，让 m 落在 0，再按 d 缩放，让标准差变成 1。这样，“比均值大多少”就变成了“比均值大几个标准差”，而曲线下的面积不会改变，可以直接查标准正态分布的表。这一步叫作标准化。

把标准化用到样本均值上。假设的真实均值记作缪零，这里是 0；标准差是西格玛除以根号 5；a 是观测到的 1.1。代进去，就得到 z。偏离可能朝两个方向，所以要看的是两侧尾部合起来的面积。

这个面积小到什么程度才算证据，需要事先约定一个标准，最常用的是 5%：如果在新工艺无效的前提下，出现这么大偏离的概率不到 5%，我们就认为它不太可能只是巧合，判定结果显著。在标准正态分布上，两侧尾部合计占 5% 时，界限正好是正负 1.96。所以，z 大于 1.96 或小于负 1.96，就等于说这个概率不到 5%。“新工艺无效”这个前提，叫作原假设；算出的两侧面积，叫作 p 值。

不过，这个计算需要用到单批数据的标准差西格玛，而实际情况下，我们通常很难直接得到西格玛的值。手上只有这五个数，西格玛也只能从它们本身估计出来。

西格玛平方衡量的是数据离真实均值有多远。在图上，每个数据到缪的距离的平方，就是以这段距离为边长的正方形的面积。如果知道缪，就可以用这五个正方形面积的平均来估计西格玛平方。重复抽样很多次，这个估计平均正好等于西格玛平方，也就是说，它没有系统偏差。

可惜缪是未知的，我们能用的只有样本均值，只好改为量每个数据到样本均值的距离。数据到样本均值的差，叫作偏差。

让参照点 c 在数轴上移动，五个正方形的面积之和随之变化。c 在 1.1，也就是样本均值的位置时，面积之和最小，是 4.78；离 1.1 越远，面积之和越大。真实的缪在哪里，我们不知道；但只要它不恰好等于样本均值，数据到缪的距离平方和就一定更大。所以，用样本均值作参照，量出来的离散程度只会偏小，不会偏大。

这个规律对任何数据都成立。把每个数据到 c 的距离拆成两段：先到样本均值，再从样本均值到 c。两边平方，再对所有数据求和。中间那一项里，样本均值减 c 对每个数据都一样，可以提出来，剩下的是所有偏差之和。样本均值是所有数据之和除以 n，所以所有数据减去它以后，加起来正好是 0，这一项就消失了。剩下的式子告诉我们：到任意一点 c 的距离平方和，等于到样本均值的距离平方和，再加上 n 乘以样本均值与 c 之间距离的平方。后面这一项不会小于 0，所以参照点在样本均值处时，平方和最小。

比如 c 取 1.5，它离样本均值 0.4，平方和就是 4.78 加上 5 乘以 0.4 的平方，等于 5.58，和刚才图上的数一样。

现在把 c 换成真实的缪，看两边在重复抽样中平均是多少。左边是 n 个数据到缪的距离平方和，平均是 n 份西格玛平方。右边最后一项，是 n 乘以样本均值误差的平方；前面已经算过，样本均值的方差是西格玛平方除以 n，所以这一项平均正好是一份西格玛平方。于是，到样本均值的距离平方和，平均只有 n 减 1 份西格玛平方。

少掉的这一份，正是样本均值本身的误差带来的。所以要除以 n 减 1，而不是除以 n，估计才没有系统偏差。这样算出的 s 平方，叫作样本方差。只有两个数据时，除以 2 得到的估计平均只有真实值的一半；有五个数据时，除以 5，平均是真实值的八成。

少掉的这一份，还可以从数据里有几条信息来理解。两个数据的情形最简单。两个数据的均值落在它们的正中间，两个偏差一样长、方向相反，每个偏差都是间距的一半。两个偏差的平方加起来，就是间距平方的一半。

两个数据可以换成两个量来描述：一个是平均位置，一个是间距。把两个点一起平移，平均位置变了，偏差却完全不变；只有改变间距，偏差才会改变。平均位置已经用来估计缪了，能告诉我们离散程度的，只剩下间距这一条信息。

间距还有一个好处：它和缪无关。两个数据相减，缪就消掉了，只剩下两个误差之差。用前面方格的办法展开，它的平方平均是两份西格玛平方，再除以 2，偏差平方和平均正好是一份西格玛平方。两个数据只有一条关于离散程度的信息，所以要除以 1。

数据更多时，道理也一样。三个数据的偏差平方和，可以拆成两项：第一项看前两个数相距多远，第二项看第三个数离前两个数的中点有多远。第二项括号里的 x 一加 x 二减 2 倍的 x 三，是中点到 x 三距离的两倍。两项里的缪都会消掉。第二项用方格展开，误差部分的平方平均是西格玛平方加西格玛平方加 4 倍西格玛平方，也就是 6 倍西格玛平方，除以 6，正好是一份西格玛平方。所以两项平均都是一份西格玛平方。

一般地，每加入一个数据，就多出一条新的信息：这个数据离前面那些数据的平均位置有多远。把这段距离平方，再乘上一个系数，前面有 k 个数时，系数是 k 除以 k 加 1，它的平均正好是一份西格玛平方。n 个数据一共有 n 减 1 条这样的信息。用开头的五批数据算一下，四项分别是 2.00、1.93、0.85 和 0，加起来正好是 4.78。最后一项是 0，是因为第五个数 1.1 恰好等于前四个数的平均值。

这就是自由度的含义：能用来估计离散程度的信息有几条。n 个数据里，有一条信息用来确定平均位置，剩下的 n 减 1 条用来估计离散程度。常说的“知道了均值，最后一个数据就不能自由取值”，说的也是这件事。被用掉的是所有数据共同的平均位置，不是其中某一个数据。

这个理解可以直接推广。如果两组数据的方差相同，就可以把两组合起来估计这个方差。两组各用掉一条信息来确定自己的均值，自由度是 n 一加 n 二减 2。用一条直线拟合散点时，要定斜率和截距两个数，就用掉两条信息，自由度是 n 减 2；一般地，要定 p 个数，自由度就是 n 减 p。

除以 n 减 1，保证了 s 平方在重复抽样中平均等于西格玛平方。但每次抽样得到的 s 仍然有大有小。数据少的时候，这种波动相当明显：只有 4 个数据时，大约六成的样本算出的 s 比西格玛小。

用 s 代替西格玛放进分母，就得到 t 统计量。s 偏小时，t 变大，越过 1.96 的可能性可以从 5% 升到接近百分之百；s 偏大时，t 变小，这个可能性最多从 5% 降到 0。两种情况的影响并不对称，再加上 s 偏小的情况更多，越过 1.96 的总概率就超过了 5%。在原假设成立、只有 4 个数据的条件下模拟一百万次，大约有 14.5% 的 t 值落在正负 1.96 以外。要定出正确的界限，就得知道 t 的确切分布。

要得到 t 的确切分布，要用到前面已经假设的正态分布，它的作用体现在间距上。以两个数据为例：间距里的误差是艾普西隆一减艾普西隆二，两数之和里的误差是艾普西隆一加艾普西隆二。两者相乘，再在重复抽样中求平均，结果是西格玛平方减西格玛平方，等于 0。乘积平均为 0，叫作不相关。

不相关，并不等于互不影响。看右边这幅图：数据均匀分布时，点团是一个菱形。如果两数之和接近 2，两个数就都得接近 1，间距只能接近 0；间距能取多大，取决于和是多少。左边的正态数据就不一样，点团是圆形的，不管和是多少，间距的分布都一样。相互独立的正态数据，经过加减组合得到的几个量，只要互不相关，就相互独立。这是正态分布特有的性质。

由此可以得到两个结论。第一，样本均值就是平均位置，s 平方只由那 n 减 1 条间距算出。用同样的方法可以验证，这些间距彼此不相关，和平均位置也不相关，所以它们全部相互独立，样本均值和 s 平方也相互独立。第二，每条间距的平方项，除以西格玛平方以后，都是一个标准正态变量的平方，而且它们相互独立。所以，s 平方除以西格玛平方，就是纽个独立标准正态变量平方的平均，这里纽等于 n 减 1。这纽个平方的和，服从自由度为纽的卡方分布；s 平方除以西格玛平方，就是它除以纽。

一个量的方差，等于它平方的平均减去它平均的平方。每一部分是一个标准正态变量的平方，它的平均是 1；它平方的平均，也就是标准正态变量四次方的平均，是 3。所以每一部分的方差是 3 减 1，等于 2。和样本均值的方差是西格玛平方除以 n 同样的道理，纽个独立部分平均以后，方差是 2 除以纽。纽等于 1 时，s 极不可靠，大约七成的时候比西格玛小；纽到了 30，s 已经相当接近西格玛了。

在原假设成立时，把 t 的分子和分母同时除以同一个量，也就是西格玛除以根号 n 的值。分子就变成一个标准正态变量，分母是 s 与西格玛之比，两者相互独立，而分母的分布只取决于纽。所以，t 的分布只取决于纽，与缪和西格玛都无关，可以事先算好，制成表格。这就是自由度为纽的 t 分布。

t 分布的形状可以这样理解：如果分母恰好等于某个值 w，t 就服从标准差为 w 分之 1 的正态分布。分母是随机的，所以 t 的分布，是许多宽窄不同的正态分布按照分母的分布加权平均的结果。分母偏小的那部分，对应较宽的正态曲线，正是它们让两侧的尾部变厚。

纽越大，分母越集中在 1 附近，t 分布就越接近标准正态分布。双侧 5% 的界限也随之变化：自由度为 3 时是 3.18，为 4 时是 2.78，到了 30 是 2.04，已经和 1.96 很接近了。如果仍用 1.96，自由度为 3 时，即使原假设成立，也有 14.5% 的机会判为显著，这就是刚才模拟的结果；自由度为 4 时，是 12.2%。

回头看，自由度起了两个作用。它是能用来估计离散程度的信息条数，决定了偏差平方和要除以几；它也是构成 s 平方的独立部分的个数，决定了 s 有多可靠，进而决定了 t 分布的形状。这两者是同一个数，因为 s 平方正是由这几条间距的平方平均得到的。

这也说明了为什么自由度可以不是整数。两组数据方差不相等时，两组均值之差的方差，要用 s 一的平方除以 n 一、加上 s 二的平方除以 n 二来估计。两项的大小不同，这个和不再是纽个同样大小的独立部分的平均，没法直接数出自由度。前面算过，纽个独立标准正态变量平方的平均，在重复抽样中平均是 1，方差是 2 除以纽；方差除以平均的平方，这个比值不随单位改变，等于 2 除以纽。所以可以反过来做：先算出这个和的方差与平均平方之比，每一项的方差都按刚才的 2 除以纽来算，再令比值等于 2 除以纽，解出一个等效的纽。这就是韦尔奇-萨特思韦特自由度。比如第一组有 5 个数据、方差为 4，第二组有 12 个数据、方差为 1，算出的自由度约为 4.86，意思是这个方差估计的可靠程度，大约相当于 4.86 个独立标准正态变量平方的平均。这样算出的自由度，总是介于 n 一减 1 和 n 二减 1 中较小的一个与 n 一加 n 二减 2 之间。

现在回到开头的五批数据。样本均值是 1.1，s 是 1.093，除以根号 5 得 0.489，t 等于 2.25，自由度是 4。如果按正态分布的界限 1.96 来判断，结果是显著的；但按自由度为 4 的 t 分布，界限是 2.78，结果并不显著。只有五个数据时，s 本身就很不可靠，如果仍然使用正态分布的界限，就会过于频繁地宣布有了发现。t 检验把 s 本身的波动也考虑了进去。

这些结论各有前提。除以 n 减 1，只要求各个误差平均为 0、方差相同、互不相关；前面推导时用了“互不影响”，其实只要不相关就够了。t 分布则要求数据相互独立，并且服从同一个正态分布。如果数据的分布明显不对称，样本又很小，t 分布就只是近似。
