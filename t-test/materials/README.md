# t 检验与自由度：视频制作资料

目标：做一支中文科普视频，讲清 t 检验，重点是自由度（为什么除以 n − 1、t 分布从哪里来）。配音已经用 TTS 生成，下一步是设计分镜，并用 HTML 做出与配音同步的高质量动画。

## 文件

| 文件 | 内容 | 用法 |
|---|---|---|
| 旁白.srt | 配音的字幕与时间轴，共 339 条，总长 21:48 | 时间以它为准，动画按它的时间戳同步 |
| 旁白.txt | 送进 TTS 的旁白原文，共 43 段 | 与 srt 内容一致 |
| 分镜对照表.md | 把脚本里每段【画面】和对应旁白，按 srt 的实际时间对齐 | 设计分镜的起点 |
| t检验视频脚本.md | 脚本原稿：【画面】描述、【旁白】、公式 | 画面描述只是文字建议，不是定稿 |
| t检验文字讲解.md | 同一套内容的完整文字讲解，推导比脚本更细 | 理解概念、核对推导时用 |
| 问题与避免方法.md | 前面写作过程中作者提出的问题，以及对应的要求 | 设计和写作都要遵守 |
| 数值复算.py | 复算脚本里出现的全部数字（需要 numpy、scipy） | 画面上的数字以它的输出为准 |

| 节 | 内容 | 时间 |

## 画面要遵守的要求

这些都来自作者的反馈，详见 问题与避免方法.md。

- 画面以代码绘制的动画为主。图片素材只作举例，用之前要真正打开、核对是否合适。
- 不用 n 维向量和投影来讲，用数轴、间距、两个数据的例子讲。
- 不用角色和对话。
- 不先抛出结论，按推导的经过一步步推进；每一步推导都要在画面上看得见。
- 不用未标明的比喻。
