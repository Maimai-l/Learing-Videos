# 播放器

给“用代码逐帧绘制”的视频用的网页播放器。画面不是视频文件，而是每一帧调用一次
`render(ctx, t)` 画在 canvas 上；有配音时以音频为时钟，没有配音时自己计时。

最早为 `t 检验与自由度` 写的，现在和那个视频的代码分开了：视频的一切（标题、时长、画面、章节、小题、音频）
都通过配置传进来。

## 试一下

ES 模块需要用 http 打开，不能直接双击文件。在仓库根目录运行：

```sh
python3 -m http.server 8000
```

然后打开 <http://localhost:8000/player/demo/>。示例是一段 48 秒、没有声音的小视频，三节，第二节末尾有一道题。

## 外观

参照苹果的播放器（Apple TV、QuickTime），能少则少：系统字体，控件直接压在画面上的渐变里，
没有任何强调色，只有白和灰。

- 开始画面：标题在左下，下面一行简介和时长，白色“播放”按钮；有上次的位置时是“继续播放 0:32”和“从头播放”。
- 播放时：底部一行，左边是视频标题和当前章节（点开章节列表），中间是播放 / 暂停，
  右边是音量、字幕、速度、章节、全屏；下面是细进度条，左边已播放时间，右边剩余时间。画面中间不放任何控件。
- 小题在画面右侧的侧边栏里，画面缩小让出位置，不被遮挡；手机竖屏时侧边栏在画面下方。
  操作是文字（“显示答案”“继续播放”“收起”），Esc 也能收起。到小题时，右上角只出现一行“第二节的小题 ›”。
- 快捷键列表（按 `?`）是压暗画面上的文字，按 Esc 或点一下回到画面。
- 鼠标不动 2.5 秒后控件淡出；暂停时一直显示。

## 功能

- 播放、暂停、0.75× 到 1.5× 变速（保持音高）、音量、全屏；前进后退用键盘（←/→ 5 秒，J/L 10 秒），上一节下一节用 Shift ←/→ 或章节列表
- 进度条按章节分段；鼠标停在进度条上，显示那一刻的画面预览和所在章节
- 章节列表；每节末尾可以放小题：先在右上角出现一行提示，也可以在章节列表里勾选“到小题时暂停”
- 小题可以写自己的答案，点“显示答案”才显示答案和解析；做过的题会记住
- 字幕由视频自己画在画面上；控制栏出现时播放器告诉视频把字幕上移，不会被挡住
- 记住播放位置、速度、音量、字幕开关，下次打开可以从上次的位置继续
- 键盘快捷键（按 `?` 查看）；系统媒体键和锁屏控制显示当前章节
- 画布按屏幕实际分辨率绘制（最多 2 倍），高分屏上也清晰

## 用法

页面引入 `player.css`，再调用 `startPlayer`：

```html
<link rel="stylesheet" href="player/player.css">
<script type="module">
  import { startPlayer } from './player/player.js';

  startPlayer({
    title: '视频标题',
    duration: 125,                     // 秒
    render(ctx, t, o) {                // 画出时刻 t 的画面
      ctx.fillStyle = '#111';
      ctx.fillRect(0, 0, 1920, 1080);
      // …
    },
    chapters: [
      { title: '开场', start: 0 },
      { title: '第二部分', start: 40 },
    ],
    quizzes: [
      { chapter: 2, question: '……', answer: '……', explain: '……' },
    ],
    audio: 'soundtrack.m4a',
  });
</script>
```

播放器会占满整个页面（`position: fixed`），并给 `html`、`body` 设置黑色背景、不滚动。

## 配置

| 字段 | 说明 |
|---|---|
| `title` | 标题。用于开始画面、无障碍标签和系统媒体控制。 |
| `titleHTML` | 开始画面的标题，可以是 HTML（比如带公式的斜体字母）。不给就用 `title`。 |
| `subtitleHTML` | 开始画面标题下面的一行，HTML。不给就不显示。 |
| `duration` | 总时长，秒。必填。 |
| `render(ctx, t, o)` | 画出时刻 `t` 的一帧。必填，约定见下一节。 |
| `width`、`height` | 画面在 `render` 里的坐标尺寸，默认 1920 × 1080。 |
| `chapters` | 章节，按顺序：`{ title, start, label?, quizAt? }`。第一节从 0 开始；`label` 是章节号（默认“一、二、三……”）；`quizAt` 是本节小题出现的时刻，默认本节结束时。不给就当作只有一节。 |
| `quizzes` | 小题：`{ chapter, question, answer, explain }`。`chapter` 是第几节（从 1 数），一节可以有多道。文字里空一行（`\n\n`）分段。 |
| `audio` | 配音或音轨的地址。不给就无声播放，由播放器计时。音频加载失败时会提示，并改为无声播放。 |
| `posterTime` | 开始画面背后显示哪一刻的画面，默认 0。 |
| `storageKey` | localStorage 里保存设置用的键，默认 `player:标题`。不同视频应该不同。 |
| `preview` | 设为 `false` 关闭进度条上的画面预览（`render` 不是 `t` 的纯函数时需要）。 |
| `load` | 可选的异步函数。播放器先显示加载动画，再等它完成；它返回的对象会合并进配置。适合在这里加载数据、等字体、构建场景，再返回 `render`、`duration` 等。 |
| `mount` | 播放器放进哪个元素，默认 `document.body`。 |
| `at` | 开发用：打开时直接暂停在这个时刻。 |

## `render(ctx, t, o)` 的约定

- **只由 `t` 决定画面。** 播放器会跳到任意时刻、为进度条预览单独画某一帧，帧的顺序没有保证。
  需要“状态”时从 `t` 算出来。
- 调用前播放器已经设好缩放（`ctx.setTransform(scale, 0, 0, scale, 0, 0)`），
  所以按 `width × height` 的坐标画就行；每帧要画满整个画面（先画背景）。
- `t` 可能小于 0 或大于 `duration`（比如 `posterTime: -1` 表示只要背景），要能正常处理。
- `o.scale`：画布像素与画面坐标之比（对齐像素时有用）。
- `o.subtitles`：字幕开关。字幕由视频自己画，关掉时就不画。
- `o.subtitleLift`：控制栏出现时，字幕应当上移的距离（画面坐标）。播放器会让它平滑变化。
- `o.preview`：是否在画进度条上的小预览图。预览图很小，可以省掉细节。

## 小题的格式

```js
{
  chapter: 2,
  question: '题目。空一行另起一段。',
  answer: '简短的答案。',
  explain: '解析。\n\n第二段。',
}
```

题目和解析是纯文本，公式用 Unicode 写（σ²/n、√5、x̄）。

## 文件

| 文件 | 内容 |
|---|---|
| `player.js` | 全部逻辑：界面、时钟、键盘、章节、小题、设置 |
| `player.css` | 样式。颜色、材质和字体集中在 `.tp` 上的变量里 |
| `demo/` | 示例视频 |

## 打包成单个 HTML

`t 检验与自由度` 的项目里有打包脚本（`t-test/tools/bundle.mjs`）：用 esbuild 把播放器、动画引擎和数据打成一个脚本，
连同样式和子集化的字体一起写进一个 HTML 文件，音频放在旁边。可以照着它给别的视频打包。

## 已知的不足

- 手机竖屏时画面很小，控件会收紧（隐藏标题、简介），但仍然偏挤；横屏正常。
- 界面文字只有中文。
- 界面用系统字体（苹果设备上是苹方），没有时退到思源黑体、微软雅黑。示例页从 Google Fonts 加载思源黑体，画面里的字用的是它。
